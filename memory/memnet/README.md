# memnet —— 经验网

给模型"抓线头"的记忆结构。

**独立包**：只依赖标准库与一个 `*sql.DB`，不 import 本仓库任何其他包。
表、阈值、动作都是它自己的，将来可以整块搬走（独立仓库 / 独立服务）。

```go
net, err := memnet.Open(db, time.Now())   // 建表 + 铺预制网（幂等）
res, err := net.Attach(now, memnet.AttachInput{Content: "…", TaskID: "t-1"}, vec, model)
heads, err := net.LineHeads(qvec, now, 4)
```

---

## 1. 它解决什么

会话记录是**流水**：按时间，给人看。它回答不了"上次踩过类似的坑吗"。
经验网是**联想**：按语义，给模型用。

一条经验 = 一句话（总结 / 用了什么技术 / 踩了什么坑，各算一条），
带 `task_id` 指回当时的完整存档——**线头在经验上，过程在流水里**。

---

## 2. 为什么是现在这个形状（都是量出来的，不是设计出来的）

### 2.1 短句向量是各向异性的

`bge-small-zh` 是为 query→passage 训练的；短句之间的余弦被压在 0.3~0.6 的窄带里。

| | 同义（8 对改写） | 无关（约 100 对） | 间隔 |
|---|---|---|---|
| 原始 | 均值 0.854，最小 **0.717** | 均值 0.483，最大 **0.649** | **+0.068** |
| **减语料均值** | 均值 0.682，最小 **0.429** | 均值 −0.128，最大 **0.214** | **+0.216** |
| 再按维标准化 | 0.352 / 0.163 | | +0.189（更差，弃用） |

→ **任何比较之前先减掉语料均值**（`Tuning.Center`，默认开）。均值是派生缓存，不进库。

### 2.2 持久化的第二层枝会"融化"

试过在五个大类下长二级枝、用成员均值当中心点。结果：一条「坑」下面同时装着
偏好、做法、事实——均值被异质成员带跑，变成"泛泛而谈"，什么都吸。

实测扫阈值：低了全糊（6 个枝、最大 6 条混装），高了全碎（18 个枝、15 个单例），**中间没有可用值**。

→ **第二层不落库**。写入只挂大类；"哪些经验像一伙的"在召回时按当前 query 现算，糊了下次重新聚。

### 2.3 名字会过期，向量不会

节点名是给抽象分类贴的标签。实测"把向量翻译成最近的词"只有一半 top-1 正确
（0.1~0.34 的弱相关），因为词表封闭、单词没有上下文。

→ **不起名**。线头直接翻译成**一句真话**（成员首句），永远准确、永远在表内。

## 3. 数据形状

```sql
mem_nodes    -- 只有 5 行：大类
  id, level, anchor, centroid, centroid_model, created_at, updated_at
  -- anchor = 种子句（定义这个大类）；centroid 锚在它上面，永不随成员重算

mem_entries  -- 一条经验
  id, content, conversation_id, task_id, source, durability,
  hits, status, last_hit_at, created_at, embedding, embedding_model

mem_links    -- 经验 ↔ 大类（多对多 = 网）
  entry_id, node_id, conductance, last_flow_at
```

预制网只有第一层，五个大类**正交于领域**（不是"编程/生活/工作"这类切分）：

| 大类 | 回答的问题 | 种子句 |
|---|---|---|
| `seed-pref` | 用户想要什么 | 用户长期稳定的喜好与厌恶：对什么顺手、对什么反感、习惯怎么做 |
| `seed-fact` | 世界是什么样 | 客观且相对稳定情况：环境、身份、账号、约定、位置 |
| `seed-how` | 怎么做到 | 把事做成的办法：步骤、工具、写法、技巧 |
| `seed-pitfall` | 什么会失败 | 失败与教训：出了什么问题、为什么、下次怎么绕开 |
| `seed-tradeoff` | 为什么这样选 | 做过的选择与理由：为什么这样选、放弃了什么 |

"用 QQ 发图被限流"和"SQLite 迁移锁表"都落在「坑」里，不需要两个种子去接。

## 4. 写入

```
向量化 → 近重复检测（cos ≥ NearDup）
            ├─ 命中：hits+1、刷新 last_hit_at、主枝加粗（不造新条目）
            └─ 未命中：argmax 大类必挂 + 其余 ≥ LinkL1 的加挂（≤ MaxLinks）
```

- **argmax 必挂**：五个大类覆盖全部经验类型，永远有家；**不因为够不着而新建大类**
  （要改分类由人加种子，不由流量决定）。
- 中心化之后余弦可以是负数（"离得很远"），**照样参与排序**——不能因为全为负就没有去处。

---

## 5. 读取

**条目优先**，不是分类优先：

```
query 向量
  → 全库 active 条目按 cos × R 排序         ← 这一步不会漏跨大类挂靠的经验
  → 取 top 40 当候选
  → 现算成簇（两两 cos ≥ NeighborSim）
  → 每簇一根线头：[N 条 · 分数] 代表句（id=…，来自 task-…）
```

- 线头**只占一行**；成员 id 只作 `dig` 的入参，不铺给模型。
- `dig{entry_id}`：翻同大类里够近的兄弟（"还有类似的吗"）。
- `dig{node_id}`：展开整个大类（"这一类都有什么"）。

## 6. 遗忘与剪枝

```
S = S₀ × growth^(hits-1)      R = exp(-Δt / S)      score = cos × R
```

| 档 | 衰减 | 例子 |
|---|---|---|
| `core` | 不衰减 | 用户身份、硬约束 |
| `durable` | 遗忘曲线（默认 S₀=30 天、×2） | 技术、坑、偏好、取舍 |
| `transient` | **不进网** | "他现在很烦""这次先这样" |

- **复现靠"又被观察到"，不靠被召回**：召回本身不加粗，否则越常想起越忘不掉，形成回音室。
- **软剪枝**：`R < PruneRetain` 只标 `pruned`（不删行、不删向量、留着 S），重新遇到能复活
  （忘掉之后再学比第一次快）。干枯的链接也会断开；条目只要还有一条线就活着。

## 7. 参数（`Tuning`，全部可调）

| 字段 | 默认 | 作用 |
|---|---|---|
| `MaxLinks` | 3 | 一条经验最多挂几个大类（1 = 单父树） |
| `LinkL1` | 0.25 | 除 argmax 外，额外大类要够的相似度（中心化后带宽） |
| `NeighborSim` | 0.30 | 两条经验算"同一簇"的线 |
| `NearDup` | 0.62 | "同一件事"的判定线（中心化后：同义 0.43~0.87、无关 ≤0.21） |
| `BaseStable` | 30 天 | 遗忘曲线 S₀ |
| `Growth` | 2.0 | 每命中一次的强度倍数 |
| `PruneRetain` | 0.15 | 软剪枝线 |
| `Center` | true | 比较前减语料均值（关掉只在测试里用） |

标定方法：拿一批**真经验 + 手写改写对**（同一件事的两种说法），量"同义最小 vs 无关最大"的间隔，
扫阈值看树形（枝数 / 最大成员 / 单例数）。别拍脑袋——上面每个默认值都是这么来的。

---

## 8. 已知限制

- **检索是全库暴力算余弦**（几千条亚毫秒）。到十万条量级要加 ANN 索引，暂不做。
- **聚类对小样本无意义**：条目少时"全是单例"是正确结果，不是 bug。
- **`transient` 的一次性内容**只活在当前任务上下文里，不进网，也不会自动清理任务存档。
- **整理（写经验）不在本包内**：`note` 是纯动作，什么时候调由上层决定。
